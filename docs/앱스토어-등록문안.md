# 앱스토어에 넣을 것 (초안)

제출할 때 App Store Connect 에 그대로 옮겨 붙일 것들. **글자 수 제한이 있는 칸은
세어서 적어 두었다.**

말투는 앱 안과 맞췄다 — 온보딩이 "일본어를 들리는 대로 쳐보세요" · "담으면 교재가
됩니다" 로 말하므로, 등록 문안만 광고 말투가 되면 열었을 때 다른 앱처럼 느껴진다.

## 이름과 부제

| 칸 | 넣을 것 | 글자 |
|---|---|---|
| 앱 이름 (30자) | `뭐라고 - 들리는 대로 일본어` | 16 |
| 부제 (30자) | `애니 대사를 한글로 쳐서 찾기` | 15 |

**이름에 `뭐라고` 를 앞에 둔다.** 검색으로 오는 사람보다 이름을 듣고 오는 사람이
먼저다. 뒤의 설명은 목록에서 무엇 하는 앱인지 한눈에 알리는 몫이다.

대안(상표 검색에서 걸리면): `소리로 찾는 일본어` · `히라가나 몰라도 일본어`

## 프로모션 텍스트 (170자 · 심사 없이 언제든 바꿀 수 있는 칸)

```
"아타마가이타이" 라고 치면 頭が痛い 가 나옵니다. 띄어 쓰지 않아도, 가나를 몰라도
됩니다. 애니 보다 걸린 그 한 마디를 들리는 대로 치세요.
```
(79자)

## 설명 (4000자)

```
들리는 대로 치면 됩니다.

"다이죠부데스카" 라고 치면 大丈夫ですか 가 나옵니다.
띄어 쓰지 않아도 어디서 끊을지 사전이 정하고,
"이타이야메로" 처럼 활용된 말도 사전형으로 되돌려 찾습니다.

기존 변환기는 "다이죠부" 에 ダイジョブ 를 돌려줍니다.
소리를 가나로 바꿔 줄 뿐 大丈夫 를 찾아 주지는 않습니다.
그 자리를 메우려고 만들었습니다.


■ 가나를 못 읽어도 됩니다

찾은 말은 가나 · 한자 · 한글 세 층으로 보여 줍니다.
가나가 맨 위인 것은 소리를 듣고 찾아온 사람에게 가장 가까운 것이 가나이기 때문입니다.
어디까지 볼지는 설정에서 고릅니다.

한자에는 한국 독음을 곁들입니다. 大丈夫 옆에 "대장부" 가 회색으로 붙습니다.


■ 담으면 교재가 됩니다

걸린 말을 갈피표로 담아 두면 그 화의 교재가 됩니다.
묶음은 마음대로 만들고 옮길 수 있고, 여러 개를 골라 한꺼번에 옮길 수도 있습니다.

담은 것은 연습 카드가 됩니다. 가나를 보고 뜻을 떠올린 다음 뒤집어 맞춰 보세요.
채점하지 않습니다.


■ 오십음도가 들어 있습니다

찾다가 막혀도 연습하다 막혀도 같은 자리입니다.
표로 보고, 한 글자씩 뒤집어 익힐 수도 있습니다.


■ 계정도 서버도 없습니다

아무것도 모으지 않습니다. 계정도, 위치도, 사용 기록도 받지 않고 어디로도 보내지
않습니다.

사전이 앱 안에 통째로 들어 있어 찾을 때 인터넷을 쓰지 않습니다.
비행기 안에서도, 지하철에서도 그대로 됩니다.
담은 말은 기기 안 파일에만 있습니다.


■ 문장 뜻은 아이폰의 번역 기능을 빌립니다

낱말 뜻은 앱 안에 들어 있어 그대로 나오지만, 문장 뜻은 iOS 18 의 번역 기능을 씁니다.
설정 앱 › 일반 › 언어 및 지역 › 번역 언어에서 일본어를 받아 두면 나옵니다.


■ 쓰는 자료

일본어 사전 JMdict · 한자 독음 KANJIDIC2 · 낱말 빈도 JESC (모두 CC BY-SA 4.0).
자주 쓰는 낱말의 한국어 뜻은 사람이 손으로 다듬었습니다.
사전에는 공개 사전을 통째로 싣기 때문에 비속어와 성적인 낱말도 들어 있습니다.
```

**앱 이름·부제에 이미 든 낱말은 넣지 않는다** — 애플이 그쪽도 함께 찾아 주므로 자리
낭비다. 그래서 `뭐라고` · `들리는` 은 뺐다.

## 연령 등급 설문

**정직하게 적는다.** 사전 앱이 이 자리에서 낮게 적었다가 되돌려지는 일이 흔하다.
JMdict 를 통째로 싣기 때문에 비속어와 성적인 낱말이 **검색으로 닿는다**(가리는 설정은
두지 않기로 했다 — 까닭은 `앱스토어-심사.md`).

| 물음 | 답 | 왜 |
|---|---|---|
| 저속한 유머 또는 욕설 | **드묾/약함** | 사전 표제어로 들어 있다. 앱이 먼저 보여 주지는 않는다 |
| 성적 내용 또는 노출 | **드묾/약함** | 같은 까닭. 그림이나 묘사는 없고 낱말과 뜻뿐이다 |
| 사실적 폭력 · 만화적 폭력 | **없음** | 낱말 뜻에 그치고 묘사가 없다 |
| 공포 · 도박 · 술·담배·마약 | **없음** | |
| 사용자 제작 콘텐츠 | **없음** | 담는 것이 기기 안에만 있고 남에게 안 보인다 |
| 웹 접근 제한 없음 | **아니요** | 앱 안에 브라우저가 없다. 출처 링크는 기본 브라우저로 나간다 |

이대로면 **12+** 가 나올 것으로 본다(확정은 애플이 한다).

## 스크린샷 (실기기에서 찍는다)

규격은 아이패드 12.9" 와 아이폰 6.7" 두 벌. **찍을 화면 다섯**을 정해 둔다.

1. **찾은 순간** — `아타마가이타이` 를 친 상태. 이 앱이 무엇인지 한 장으로 말하는 화면
2. **문장 뜻까지** — 조각 카드와 문장 뜻 줄이 함께 보이는 상태
3. **책장** — 묶음 두셋에 낱말이 담긴 상태(빈 화면은 찍지 않는다)
4. **연습 카드** — 뒤집기 전 앞면
5. **오십음도** — 가나를 못 읽어도 된다는 것을 보여 주는 자리

담은 것이 없는 빈 상태로 찍으면 앱이 비어 보인다. **찍기 전에 낱말을 열댓 개 담아
둘 것.**
