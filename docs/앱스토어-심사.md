# 앱스토어에 내기 전에 (2026-09-06 점검)

지금까지 만든 것을 앱스토어 심사 기준에 대고 훑었다. **코드가 아니라 자료와 계정이
걸린다** — 앱 자체는 계정도 서버도 네트워크도 없어서 심사가 까다로울 자리가 적다.

## 막는 것

### 1. EXAONE 모델 라이선스 — 가장 큰 위험

한국어 뜻 34,571개를 **EXAONE 3.5 7.8B**(LG AI Research)로 구웠다(`Tools/Translator`).
그 모델은 Apache 나 MIT 가 아니라 **자체 라이선스**이고, 상업적 이용과 **모델이 만든
출력물**에 조건이 붙는다.

**배포 전에 라이선스 원문을 읽어 확인할 것.** 여기서 막히면 뜻을 다시 구워야 하고,
그것이 이 앱에서 가장 오래 걸린 작업이다(대상 23,055개). 갈 수 있는 길:

- 라이선스가 허용하면 그대로 간다. 출처를 Credits 에 적는다.
- 안 되면 **재배포가 자유로운 모델**로 다시 굽는다(Apache 2.0 계열).
  파이프라인은 `--ollama <모델>` 하나만 바꾸면 되고, `clean-gloss.py` 와
  `gloss-holes.sh` 가 그대로 쓰인다.
- 손으로 적은 표(`guardrail-gloss` 906 · `corrected-gloss` 700 · `function-gloss` 294)는
  사람이 쓴 것이라 이 문제와 무관하다.

### 2. 유료 개발자 프로그램

지금은 무료 개인 팀이라 **배포 자체가 안 된다.** 7일마다 만료되는 개발 프로파일로는
기기에 얹는 것까지만 된다. 연 $99 의 Apple Developer Program 이 필요하다.

## 준비해야 하는 것

### 3. CC BY-SA 4.0 — 동일조건변경허락

싣는 자료가 전부 CC BY-SA 4.0 이다(JMdict · kanjidic2 · Tanaka Corpus · JESC).
**저작자 표시는 이미 한다** — 설정 › 이 앱이 쓰는 자료.

남은 것은 **동일조건변경허락**이다. 구운 색인(`mworago-dict.db`)과 빈도 목록은
그 자료의 2차적 저작물이라 같은 조건으로 내놓아야 한다.

**받을 자리를 Credits 에 적어 두었다(2026-09-06).** `Credits.sourceAddress` 한 줄이고,
화면에는 "색인과 굽는 도구는 여기에 있습니다" 로 나온다. **다만 지금 그 주소가 열리지
않는다** — 레포가 비공개다. 공개로 돌리거나 GitHub Pages 를 켜서 주소를 만든 뒤
그 한 줄을 바꿔야 조건을 지킨 것이 된다.

앱 코드 자체는 2차적 저작물이 아니다(단순 결합). 앱을 열어 두라는 뜻은 아니다.

### 4. 연령 등급

**사전에 비속어와 성적 표현이 들어 있다.** JMdict 를 통째로 싣기 때문이고, 검색으로
닿는다(손으로 적은 뜻 중에도 있다). 등급 설문의 "저속한 유머 또는 욕설"·"성적 내용"을
**정직하게 표기할 것.** 사전 앱이 이 자리에서 낮게 적었다가 되돌려지는 일이 흔하다.

**가리는 설정은 두지 않기로 했다(2026-09-06 재 보고 결정).** 두 가지가 걸린다.

**① 꼬리표가 그 일을 못 한다.** 색인에 실린 사용역 태그를 세어 보니 `vulg` 182 ·
`derog` 342 · `sens` 163 뿐이고, 정작 가려야 할 낱말에 아무 태그도 없다 —
`セックス` · `ペニス` · `レイプ` · `娼婦` · `童貞` 이 전부 빈칸이다(JMdict 원본에서도
`<misc>` 가 비어 있다). 태그로 만든 가리개는 켜도 안 가려지는 가리개다.

**② 가리면 틀린 답이 올라온다.** 이 앱이 하는 일은 "방금 들은 말이 무엇인가"에
답하는 것이다. 어떤 낱말을 결과에서 빼면 그 자리가 비는 것이 아니라 **다음 후보가
대신 올라온다** — 사용자가 들은 것과 다른 낱말이 답으로 제시된다. 손으로 적은 뜻
표에 적어 둔 규칙과 같은 자리다: "빈 채로 두면 영어가 남을 뿐이지만, 틀린 한국어는
사용자가 믿는다."

그러니 **연령 등급 설문에 정직하게 적는 것**이 이 자리의 답이다. 가리개가 있어도
끌 수 있는 이상 등급이 내려가지도 않는다(심사는 닿을 수 있는 내용으로 매긴다).
개인정보 처리방침(`docs/privacy.md`)에도 가리지 않는다고 적어 두었다.

### 5. 등록에 필요한 두 주소

**글은 써 두었다(2026-09-06)** — `docs/privacy.md` · `docs/support.md`.
**주소는 아직 없다.** 레포가 비공개라 둘 다 열리지 않는다.

- **개인정보 처리방침 URL** — 모으는 것이 없어도 앱스토어 등록에는 반드시 필요하다.
- **지원 URL** — 언어팩·책장·안 나오는 낱말까지 자주 묻는 것을 함께 적어 두었다.

레포를 공개로 돌리거나 GitHub Pages(`docs/` 폴더)를 켜면 둘 다 주소가 생긴다.
그때 `Credits.sourceAddress` 와 `Settings.feedbackAddress` 도 함께 본다.

## 이미 되어 있는 것

| | |
|---|---|
| 개인정보 보고서 | `MworagoApp/PrivacyInfo.xcprivacy` — 모으는 것 없음·추적 없음 |
| 사유를 밝혀야 하는 API | 쓰지 않는다. `UserDefaults` 대신 파일에 적는다(`PreferenceStoring`) |
| 수출 규정 | `ITSAppUsesNonExemptEncryption: false` |
| 공개 API 만 쓴다 | 번역은 `Translation`(iOS 18+), 소리는 `AVSpeechSynthesizer` |
| 최소 기능(4.2) | 사전·분절·번역·연습을 갖춘 앱이라 걸릴 자리가 아니다 |
| 글꼴 | Zen Maru Gothic · 고운돋움, 둘 다 SIL OFL 1.1 |
| 네트워크 | 없다. 의견 보내기는 `mailto:` 라 권한도 서버도 필요 없다 |
| 기기 정보 | 의견 메일 본문의 iOS 버전은 사용자가 보고 지울 수 있다 |

## 아직 안 본 것

- **앱 이름 `뭐라고`** — 상표 검색은 안 해 봤다.
- **아이콘·스크린샷** — 심사 기준이 아니라 등록물이다. 아이콘은 있고
  스크린샷은 실기기에서 찍어야 한다(아이패드 12.9" · 아이폰 6.7" 규격).
- **번역기 언어팩 — 화면이 말한다(2026-09-06).** 일→한 팩이 없으면 문장 뜻 자리에
  무엇을 해야 하는지 적힌다(`TranslationPack.notice`). 받을 수 있는 기기와 아예 못
  하는 기기를 갈라 말하고, 낱말 뜻은 그대로 나온다는 것도 함께 말한다. 앱이 앞으로
  돌아올 때 다시 물으므로 설정에서 받아 오면 그 자리에서 사라진다.
  **실기기에서 눈으로 본 확인은 아직 없다** — 시뮬레이터에는 일→한 팩이 없다.
